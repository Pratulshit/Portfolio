<p align="center">
  A modern, responsive personal portfolio website built with <b>HTML, CSS and JavaScript</b>.<br>
  It showcases my skills, education, certificates and a working contact form.
</p>

---

<h2 align="center">🚀 Features</h2>

<h3>
  ✅ Responsive design for desktop, tablet and mobile<br>
  ✅ Animated typing effect in the hero section<br>
  ✅ Interactive skills network with live flowing animation<br>
  ✅ Animated education timeline with scroll reveal<br>
  ✅ Certificates gallery<br>
  ✅ Working contact form (sends email via FormSubmit)<br>
  ✅ Downloadable resume<br>
  ✅ Smooth scrolling and active navbar highlighting
</h3>
